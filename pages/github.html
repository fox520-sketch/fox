GitHub

GitHub 讓開發者、團隊與程式碼集中在同一個平台，適合版本控制、協作開發、Code Review、自動化流程與專案管理。

直接前往網站 回首頁看全部網站

主要功能

  • 程式碼託管建立 Repository 管理原始碼與版本紀錄。
  • 協作與審查使用 Pull Request、Code Review 與 Discussions 協作。
  • Issue 與專案管理追蹤任務、Bug、需求與開發進度。
  • Actions 自動化建立 CI/CD、測試、部署與其他自動化工作流程。
