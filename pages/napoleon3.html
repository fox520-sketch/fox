Napoleon3

Napoleon3 是 fox520-sketch.github.io 上的新網站專案。本頁提供網站直連、網址複製、QR Code 與獨立留言板。

直接前往網站 回首頁看全部網站

主要功能

  • 網站快速入口可從狐狸小站首頁最前面的卡片直接開啟 Napoleon3。
  • 網址複製可一鍵複製 Napoleon3 網址，方便分享給其他人。
  • 獨立介紹頁保留單獨頁面，集中放置介紹、連結、QR Code 與留言。
  • 獨立留言板留言只屬於 Napoleon3 頁面，並儲存在瀏覽器本機。
